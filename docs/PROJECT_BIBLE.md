# JARVIS OS Project Bible

## Mission
JARVIS OS is a personal AI operating system, not a dashboard.

## Core Pillars
- AI Assistant (JARVIS)
- DJ Workspace
- Producer Workspace
- Business
- Bar Management

## Design Principles
- Matte black base
- Tactical red accents (#e50000)
- Glassmorphism panels
- Smooth, purposeful animations
- Minimal clutter

## Architecture Rules
- Navigation always goes through the Router.
- Shared application state lives in the global store.
- Modules are isolated under /features.
- Reusable UI belongs in /components.
- Business logic belongs in /services.

## Coding Standards
- TypeScript only
- Reusable components
- No duplicated logic
- Strong typing
- Small focused files
